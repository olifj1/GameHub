# GameHub v1.8.23

This release feeds the measured pastel-dollhouse proportions into **My House** and makes the central circulation spaces part of the playable decorating system.

## Updated in this version
- Main room proportions now follow the measured reference more closely: approximately **4.45 m wide × 2.50 m high**, with a **2.22 m central core** and shallower room depth.
- Rebuilt the central stair as a compact **rear dog-leg / return stair**, leaving usable open space at the front.
- Added **Hall** and **Landing** as real saved rooms, with their own floor/wall finishes, furniture, lighting, clearing and active-room selection.
- Hall and Landing furniture placement is kept to the open front area so items do not collide with the stair.
- Added a small default hall table/lamp and landing plant to prove the new spaces can be dressed and lit.
- Existing bedroom/living/kids/kitchen furniture has been pulled into tighter reference-like spacing rather than spread across oversized rooms.
- Reduced the forced WebGL canvas height so the lower decorating controls fit more comfortably on shorter phones.
- Reset the My House save key because the house dimensions and room IDs changed.
