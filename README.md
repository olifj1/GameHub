# GameHub v1.8.4

Tower Attack four-route drag-deployment prototype.

- Removed the round/wave structure in favour of a continuous battlefield economy.
- Four attack routes are now available.
- Quick slots can hold either attacking vehicles or defensive weapons.
- Drag attackers to a route entrance; drag defences to highlighted emplacement points.
- Command pauses the live battlefield so quick slots can be remapped safely.
- Basic opposing AI now attacks and builds defences so both deployment types can be tested.
- Armed vehicles stop to fight; Scouts continue running for the enemy base.
