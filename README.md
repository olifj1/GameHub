# GameHub v1.7.3

- Colour Blocks keeps the 2×2 rotation mechanic from v1.7.2, but now has a more mature, desaturated visual treatment.
- The board now uses thinner dark internal grid lines and stronger quadrant separators, closer to the reference puzzle style.
- Tile colour now comes mainly through coloured hatching rather than solid childlike fills.
- The 2×2 selection frame has been restyled to match the cleaner graphic-design look and no longer uses top/bottom dots.
- Medium and Hard puzzles now scramble much more thoroughly so the board looks genuinely mixed rather than nearly solved.
- Star ratings have been relaxed so good trial-and-error solves can still earn more than one star.
- Roller Coaster remains parked: its files are preserved but it stays hidden from Home and Progress.
