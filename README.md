# GameHub v1.8.3

Tower Attack live-deployment and visual polish pass.

- Planning screen now configures four reusable deployment buttons rather than buying a fixed wave.
- During battle, tap a deployment button to spend cash and launch that vehicle immediately.
- Pause returns to planning with the battlefield frozen; remap vehicles/routes, then return to the same battle.
- Round ending is manual once active vehicles are clear; funding and defender upgrades still happen between rounds.
- Added dust trails, damage smoke, recoil and stronger vehicle/turret combat feedback.
- Expanded the procedural scenery vocabulary with richer trees, rock clusters, ruins, monoliths and ground storytelling details.
- Turrets sit farther from the roads and remain route-specific so the crossover does not create accidental cross-fire.
